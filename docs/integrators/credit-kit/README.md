# SlicerX credit kit

Material for products built on SlicerX: badges that credit SlicerX, a button that points people to support it, ready text, and screenshots for an announcement. Read `usage.md` first. It is one page.

The badges and the button come from `editions/slicerx/brand/credit.mjs` in the SlicerX repository, which draws them from the brand geometry with the type outlined, so the SVGs render the same anywhere.

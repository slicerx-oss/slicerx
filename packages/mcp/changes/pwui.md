### Added

- `slicerx_printer_list` returns `webUi` for each printer: the address of its own web page (Mainsail or Fluidd on Klipper, OctoPrint, PrusaLink, Duet Web Control) on the local network, for the person to open, or null when it has none SlicerX knows of, or its saved host is not on the local network. Built from the saved printer: its connection, its model (QIDI's Fluidd on 10088, a Creality K2's on 4408) and, where the page shares the connection's server, its saved port. The printer list from the hub, on the computer and on a paired phone, carries that saved `port` and `tls` (true when the connection uses TLS, which makes a page on the same server https). A saved host a browser would read as an IPv4 number (`134744072`, `0x08080808`) or as octal (`010.0.0.1`) is no longer taken as a local network host, here or by `slicerx_printer_add`.

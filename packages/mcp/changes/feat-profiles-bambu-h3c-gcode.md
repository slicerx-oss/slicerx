### Changed

- `machine:bambu-h3c` now carries the Bambu Lab H3C's own start, end, layer change, filament change, pause and time lapse G-code. `slicerx_slice_file` and `slicerx_estimate_file` slice an H3C plate with it: each filament change runs the printer's own change block, and a filament's hotend heater is turned off (`M104 I<filament> S0`) after the last change away from it. On the H3C the stock G-code's hotend ids are `-1`, as the printer's stock output writes them, and the per-hotend nozzle ids still name each filament's hotend. A stock filament named for a slot, and the default filament, give the G-code each slot's preset id (`filament_ids`) and fin extrusion safe temperature (`fins_extrude_safe_temp`); a filament without that temperature takes its material's generic value for the printer, else 0. The `.gcode.3mf` names each filament's hotend in slice_info (`group_id`, the TPU hotend with its own volume type) and the H3C's model id. No tool's input or answer shape changes, so no tool version moves.

### Added

- `slicerx_design_lookup_sizes` 1.0.0, in the mimir tab: looks a real thing's sizes up on the web before mimir plans a model of it. It takes the thing's name and the sizes to find, and returns a lookupId, each size found in mm with what the source said, the sizes no source gave, and the source pages, shown to the person as a lookup card. A local model is not offered it, and a slicing or printer turn at the tool limit leaves it out. Where no web lookup can run it says so: "Web lookup is not available here, so give the real sizes from what you know; the plan says they were not looked up".
- `slicerx_design_get_plan` 1.0.0 reads a kept plan back by its planId, as `slicerx_design_check` holds the part to it: its features and sizes, its scale and real sizes with where each came from, the design it is tied to, its origin (client or card) and its revision. An unknown planId is refused.

### Changed

- `slicerx_design_plan` 1.17.0 (from 1.15.1), in the mimir tab: a display or fine plan's real sizes each give the lookupId `slicerx_design_lookup_sizes` returned, or `stated`, the person's own words from the chat, and the plan is held to scale against the figure the lookup found or the words give (within 1% of the size's mm), not against the plan's own number. Where a lookup can run, a real size with neither is refused: "real: Deck length and Main tower height have no lookupId, so they are not from a lookup; call design.lookup_sizes first, then give each found size with its lookupId, or name a size the lookup did not find in assumptions as "real: Main tower height not given by the source"". A lookupId from no lookup in the chat, a size the lookup did not find within 1%, stated words not in the person's messages or giving no such size, and a "not given by the source" note for a size no lookup asked for are each refused with what to give instead. A size a lookup asked for and found no source for, and every real size where no web lookup can run, is taken from memory, and the plan says so in its assumptions ("real: not looked up, as no web lookup can run here; Deck length is from memory"). The description of `real` and the plan's guidance say to look the sizes up first, and a plan with no proportions is told to give "a lookup (design.lookup_sizes) or a stated source".
- `slicerx_design_put_plan` 1.9.0 (from 1.8.0) takes a model of a real thing's `scale` and `real` sizes, each with its `source` page ({title, url}) or the person's words as `stated`, and holds the planned sizes to them at scale within about a third, as `slicerx_design_plan` holds a display plan. A real size with neither is kept as from memory, since many clients have no web search, and the plan says so in its assumptions: "real: no source given; Deck length is from memory". The kept plan's result reads its scale and real sizes back.
- `slicerx_design_check` 1.25.0 (from 1.24.3): a display or fine plan's passing reply also says where its real sizes came from: the sizes taken from memory, by name, or the page its lookup read.

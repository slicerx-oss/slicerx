### Fixed

- Overrides and config checks refuse 0 for the bridge flow ratio, internal bridge flow, layer height, first layer height, filament diameter, flow ratio, nozzle diameter, nozzle height and the three extruder clearances (`bridge_flow`, `internal_bridge_flow`, `layer_height`, `initial_layer_print_height`, `filament_diameter`, `filament_flow_ratio`, `nozzle_diameter`, `nozzle_height`, `extruder_clearance_height_to_lid`, `extruder_clearance_height_to_rod`, `extruder_clearance_radius`). Their lower limit is now 0.01. `slicerx_slice_file` and the other tools that take overrides are refused with `Invalid overrides` and the setting's usual range message, such as `Layer height is 0; it must be at least 0.01 mm.`, and `slicerx_validate_config` reports an `out_of_range` error. `slicerx_explain_setting` gives `min` 0.01 for the internal bridge flow, filament diameter, nozzle diameter, nozzle height and the clearances. Before, 0 was taken and passed on to the slice. A project file that holds 0 still opens with the file's value.

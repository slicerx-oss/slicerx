### Added

- `slicerx_design_rename_part` 1.0.0 renames an existing part of a design, as a step named "Rename <old> to <new>": it replays, saves and undoes like any step, so a part from an opened file or a piece a cut or split made ("Hull top top") can take a plain name. `part` is from 0 and `name` is taken plain (no space at either end, each run of spaces one space). An empty name is refused with "name: give the part a name", one longer than 120 characters with "name: keep the name to 120 characters (this one has N)", another part's name, in any case, with "name: part N is already called X; give this one a name no other part has", and the part's own name with "name: part N is already called X".
- `slicerx_app_part_rename` 1.0.0 renames one part of an object open in the app, as Rename in the object list (double-click or F2 on the part, or Rename in its menu), with the same name rules and refusals: one toolbar Undo, and with a CAD history it is the same step. The part's filament, print settings and paint stay with it. Returns the parts read back, with `changed` false when the part already had that name.

### Changed

- `machine:sovol-sv04` is a two-extruder printer now, with machine settings from Sovol's firmware source: two 0.4 mm nozzles, extruder offsets of zero (the firmware parks the idle carriage and applies its offset itself), a 300 x 300 x 400 mm volume and the firmware's speed, acceleration and jerk limits. `slicerx_slice_file` and `slicerx_estimate_file` slice a two-filament plate on it with `T0` and `T1` tool changes, each followed by an `M109` wait for the new tool's temperature, and the start G-code heats both nozzles when the plate uses both. Before, it was read as a single-extruder printer and every color change was an `M600` manual swap. The profile tools read the new settings back (`nozzle_diameter` has two entries). No tool's input or answer shape changes, so no tool version moves.

### Changed

- `slicerx_design_edit_step` 1.13.0 leans the separate copies of a part with the part. A `tilt` asked of the step that made a part leans, in the same edit, every later array of separate copies of that part, each copy about its own foot. Before, only the part leaned and its copies stayed upright. The edit is refused whole, with the copy named, when a copy's lean would run it into another step.

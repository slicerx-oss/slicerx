### Fixed

- Tools that change what the open app shows, a display preference, this server's working project or a file are no longer listed as read-only. `slicerx_app_ui_set`, `slicerx_app_plate_show`, `slicerx_app_look_set`, `slicerx_app_units_set`, `slicerx_app_pick_filter_set`, `slicerx_app_preview_set`, `slicerx_app_preview_markers_set`, `slicerx_app_preview_playback_set`, `slicerx_app_preview_gcode_jump`, `slicerx_app_select_other`, `slicerx_app_model_push_set`, `slicerx_app_dimensions_show`, `slicerx_app_paint_preview`, `slicerx_app_paint_from_texture`, `slicerx_project_open`, `slicerx_project_add_model` and `slicerx_sxlock_open` now have `readOnlyHint: false`. `slicerx_project_open` is marked destructive, since it replaces the working project, and `slicerx_project_add_model` and `slicerx_sxlock_open` are marked open world. Their permission class is still read, so the policy runs them as before.

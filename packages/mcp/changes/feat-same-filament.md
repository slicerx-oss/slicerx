### Changed

- `slicerx_design_check` 1.19.0: for a display or fine plan with color in play in the design (its parts use more than one filament, or a part has color paint), the result gives `notes`, one for each small part in the same filament as the part it sits on ("Boat is the same filament (2) as Deck, which it sits on, so it will hardly show. Give it another filament, or paint Deck under it."). It never fails an item. A check that passes says in its summary to pass the notes on in the reply ("Say this in the reply too, as a suggestion: ..."); a failed check's summary is as before. The check's `body` gives each part's box, slot, name and whether it is painted, as `partBoxes`, for a design of several parts.

### Changed

- `slicerx_slice_file` 1.18.0, `slicerx_estimate_file` 1.15.0 and `slicerx_arrange_file` 1.3.0 list in a `project_gcode_review` refusal's `details.script_reviews` only the engine's reviews of the settings in `details.changes`, matched by key and filament slot. Before, every imported script the engine reviewed was listed, including filament start and end G-code the stock table had already accepted, which always reads `stock_version_unknown` because the engine's catalog has no filament G-code. A Bambu Lab H3C project whose only change was its end G-code came back with 16 filament entries and none for the end G-code. When none of the changed settings has an engine review, `script_reviews` is left out. A successful slice still returns every review in `script_reviews`, as before.

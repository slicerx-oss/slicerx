### Fixed

- `slicerx_slice_file` and `slicerx_estimate_file` slice a 3MF project on the printer it was made for with the file's plate type (`curr_bed_type`, which picks the bed temperatures), its prime tower spot as the file gives it (`wipe_tower_x` and `wipe_tower_y`) and each filament's maker (`filament_vendor`). Before, the plate type fell back to the printer's default, the tower spot was rounded to 0.1 mm and every filament's maker was `(Undefined)`. A file's "Default Plate" still means the printer's default.
- The same tools slice another slicer's 3MF project on the printer it was made for with every printer setting the file holds, listed as changed or not, as `sx project-settings` reads it: air filtration, fan direction, the silent mode machine limits and the extruder colors among them. Before, a printer setting took the printer profile's value. The file's machine G-code still goes through the G-code review, and its bed height and areas, nozzle, clearances, firmware and connection stay the profile's. A slice for another printer leaves the file's printer settings behind, as before.

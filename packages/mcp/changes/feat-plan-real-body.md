### Changed

- `slicerx_design_plan` 1.18.0, in the mimir tab: a display or fine plan that gives real sizes names its main body's real size in `realBody`, as `{feature, size, mm, source}` with `source` `lookup` and its `lookupId`, or `stated` with the person's words in `stated`. It is read as that size's row in `real`, first and in place of any row `real` gives for the same size, so the plan keeps one list of real sizes and the body's size is held to its lookup, to the person's words and to scale as every real size is; the card and design.check read `real` as before. `source` `lookup` without a `lookupId` is refused. A plan whose real sizes leave every main body out is refused with "realBody: give a main body's real size (its length), a feature in curved or flat, so the scale is set by the thing itself", in place of "real: give a main body's real size too (its length), so the scale is set by the thing itself"; a row for a main body in `real`, the older form, still counts.

### Added

- `slicerx_project_object_nozzle` 1.0.0: on a printer whose nozzles are not all one size, print an object with another nozzle (1-based: the extruder or the tool). On a tool changer the object moves to the filament on that tool; on a two-extruder printer the filament map sends its filament there. A filament other objects share is refused until the call sends `new_filament` (a copy of the filament for this object), `move_filament` (the filament, and every object printed with it, moves to that nozzle; when a painted object also uses the filament, the move is refused, naming the objects, unless `confirm_painted` is true, and the answer lists them in `paintSplit`) or `filament` (an existing one on that nozzle). With `--app` it edits the project open in the app (app link method `project.object_nozzle`) and reads back each object's nozzle and the plate's map.
- `slicerx_project_show` gives each object's `nozzle` and `nozzleMm`, the printer's `nozzles` and the `filament_map` (`manual`, or `seeded` when the slice sends the shown map by hand) when the nozzles differ in size. `slicerx_slice` gives each object's `nozzleMm` in each plate's `featureFilaments` then, and `slicerx_slice_file` gives `nozzle_mm` in `feature_filaments`. A project object moved to another filament prints with it in the server's own slice.
- `slicerx_printer_add` takes `nozzles`, one size per nozzle on a printer with two or more, checked against the model, and reads them back.

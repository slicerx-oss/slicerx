### Fixed

- `slicerx_design_plan` 1.23.0 (from 1.22.0), in the mimir tab, refuses a build's amend that adds a feature while the plan's fix round is open (a check of it failed and the check that ends the round has not come): "add: the plan's fix round is open, and an amend in it adds no feature, since Mainmast base would be one more feature the check needs a step tagged with its name for; fix the failed items on the part as planned, and for a planned feature built on another planned one, send the features with its on changed and no add". The plan stays as it was and no card shows, so the round's one amend is still there to use. Before, the amend was taken, and the next check failed its feature count, since nothing in the round built the added feature: a ship plan amended with "Mainmast base" failed `feature count (want 11, got 10 steps for 11 planned features)`. An amend before the first failed check, and a change the person asked for (`asked`), still add features. The description says an amend adds no feature while the fix round is open.

Inside the sides of what it stands on: "make it 2.61 mm tall from its base at z 12, so 2 mm shows above the top of Hull, whose lowest point under it is at z 12.61 mm: with design.edit_step, set the size of the step that makes Forecastle deck to 2.61 mm along z, or move it by [0, 0, 0.61] and set its size to 2 mm along z". Past those sides, where the sunk part shows, it says so and gives the move alone. Before, it said only to build the part from the top, and a fix round raised a deck sunk 0.61 mm to 3 mm where 2.61 mm was needed, so the next check failed it again.

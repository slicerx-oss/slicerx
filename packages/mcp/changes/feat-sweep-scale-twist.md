### Changed

- `slicerx_geom_sweep` 1.4.0 (from 1.3.0) tapers and turns the profile along its path: `scale` is its size at the end against the start (one number, or `[u, v]` along the profile's own axes, each 0.05 to 20), `twist_deg` turns it about the path by the end (counterclockwise looking back along the path), and `ease` (`linear` or `smooth`) sets how both run by length along the path. A path of `points` takes `smooth: true` to sweep along a smooth curve through them instead of straight lines between them. With `design` all of them are kept on the step, so the design's history shows it as a tapered or twisted sweep and a saved 3MF opens with them. A bad value is refused with `invalid_input` naming its field (`scale`, `scale.1`, `twist_deg`, `path.smooth`). A taper that makes the sides cross at a tight bend is refused with the point near the bend and asks for a wider bend, a smaller profile or a smaller end scale.

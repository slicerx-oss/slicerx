# sx-ffi (libslicerx)

The C ABI over `sx_core::api`, built as `libslicerx` (cdylib and staticlib). The header `include/slicerx.h` is generated by cbindgen from `src/lib.rs` on every build; CI diffs it so ABI changes are visible. Changes are listed in `CHANGELOG.md`, and `SX_ABI_VERSION` goes up on any breaking change.

## Public API

```c
uint32_t sx_abi_version(void);
uint64_t sx_mesh_load(const uint8_t *data, size_t len, const char *file_name); /* 0 on error */
void sx_mesh_free(uint64_t mesh);
SxResult *sx_slice(const char *request_json);                                 /* NULL on error */
SxBuffer sx_result_json(const SxResult *result);
SxBuffer sx_result_gcode(const SxResult *result);
SxBuffer sx_result_preview(const SxResult *result);                           /* SXPV */
void sx_buffer_free(SxBuffer buffer);
void sx_result_free(SxResult *result);
const char *sx_last_error(void);                                              /* per thread */
```

The request is the `SliceRequest` JSON (`sx schema request`) with object `mesh` values set to ids from `sx_mesh_load`. The result JSON is the same document `sx slice --request` prints. Every call is thread-safe.

Licensing: `libslicerx` is Apache-2.0. It does not use the AGPL stock profile data in `packages/profiles` (`docs/licensing.md`).

## Dependencies

- `serde_json` 1.0.151: request and result JSON.
- `cbindgen` 0.29.4 (MPL-2.0, build only, no default features): generates the header.

## Status

`tests/run-c-test.sh` builds the static library, compiles `tests/c/slice_reference.c` against the header and slices the reference plate: 508 layers, 12.5 MB of G-code, 11.9 MB of SXPV.

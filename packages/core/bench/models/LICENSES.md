Regenerate the models with `python3 generate.py` in this folder.

The 80-byte STL headers that `generate.py` and `suite.py` write still name MPL-2.0, the license these models had before. They are kept so that regenerated files stay byte for byte the same as the committed ones; the table above is the license that applies.

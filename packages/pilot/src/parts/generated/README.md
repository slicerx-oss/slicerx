# Generated

`standard-parts.json` is generated by `scripts/build-parts.ts` from a folder of checked category files (bearings.json, motors.json, phones.json and so on). Do not edit it by hand; run `pnpm --filter @slicerx/pilot parts:build <folder>`.

Every value is a published size or formula restated as a fact, with the page it came from in `source_url`. The table copies no text or drawings from those sources, and the source documents are not in the repository. None of the sources grants a data license: the values are used as facts with attribution to their makers, whose trademarks stay theirs. Several sources say their figures are for reference only (Raspberry Pi 5 dimensions are approximate; Apple and Google sizes vary by configuration), so check the exact part before making a mating part.

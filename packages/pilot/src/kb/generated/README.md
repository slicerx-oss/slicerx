# Generated

`kb.json` is generated by `scripts/build-kb.ts` from `knowledge/`, and one `edition-kb.<id>.json` per edition from that edition's own knowledge (`ai.brain.knowledge` in `editions/*/edition.config.ts`), every entry tagged with its id, so each edition's build ships only its own file. Do not edit them by hand; run `pnpm --filter @slicerx/pilot kb:build`.
